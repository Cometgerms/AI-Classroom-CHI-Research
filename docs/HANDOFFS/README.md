# Immutable session handoffs

Create YYYY-MM-DD_HHMM_<short-topic>.md at the end of every substantive session (local clock; record timezone). Never overwrite a prior handoff.

Required sections: Goal; Completed; Files Changed; Models / Dependencies; Commands Run; Tests; Current Runtime State; Known Issues; Decisions Made; Next Recommended Actions; Do Not Assume.

Update ../CURRENT_STATE.md after writing the handoff. Architectural decisions are append-only in ../DECISIONS.md.
